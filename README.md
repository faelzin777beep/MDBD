# Sistema Acadêmico Banco de Dados

## Sobre o projeto

O Sistema Acadêmico Banco de Dados é um projeto desenvolvido para organizar e armazenar informações relacionadas a um sistema acadêmico. O banco foi estruturado para representar entidades como alunos, professores, cursos, disciplinas, avaliações, boletins, turmas, coordenadores e outras informações relacionadas ao ambiente escolar.

## Funcionalidades

- Criação do banco de dados acadêmico
- Criação das tabelas do sistema
- Organização dos relacionamentos entre as entidades
- Armazenamento de informações de alunos
- Armazenamento de informações de cursos
- Armazenamento de informações de disciplinas
- Armazenamento de informações de avaliações
- Armazenamento de informações de boletins
- Armazenamento de informações de turmas
- Armazenamento de informações de coordenadores
- Inserção de dados para testes do sistema
- Modelagem do banco de dados

## Tecnologias utilizadas

- MySQL
- SQL
- brModelo
- Git
- GitHub

## Estrutura do projeto

```text
sistema-academico-banco-de-dados/
├── BRmodelo1/
├── MDB_RAFA.sql
├── escola_mdbd.sql
├── README.md
└── outros arquivos relacionados à modelagem
```

A pasta de modelagem contém os arquivos utilizados para representar a estrutura do banco de dados. Os arquivos SQL contêm a criação das tabelas, relacionamentos e dados utilizados no projeto.
