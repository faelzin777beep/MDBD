# Sistema Acadêmico Banco de Dados

## Sobre o Projeto

O Sistema Acadêmico Banco de Dados é um projeto desenvolvido para organizar e armazenar informações relacionadas a um sistema acadêmico. O banco foi estruturado para representar entidades como alunos, professores, cursos, disciplinas, avaliações, boletins, turmas, coordenadores e outras informações relacionadas ao ambiente escolar.

## Funcionalidades

- Criação do banco de dados acadêmico
- Criação das tabelas do sistema
- Organização dos relacionamentos entre as entidades
- Armazenamento de informações de alunos
- Armazenamento de informações de professores
- Armazenamento de informações de cursos
- Armazenamento de informações de disciplinas
- Armazenamento de informações de avaliações
- Armazenamento de informações de boletins
- Armazenamento de informações de turmas
- Armazenamento de informações de coordenadores
- Armazenamento de outras informações relacionadas ao ambiente escolar

## Tecnologias Utilizadas

- MySQL (ou outro sistema gerenciador de banco de dados utilizado)
- SQL (linguagem para manipulação e definição de dados)
- Ferramentas de modelagem de banco de dados (como MySQL Workbench, DBeaver, etc.)

## Estrutura do Projeto

- `BRmodelo1/`: Pasta contendo diagramas ou modelos visuais do banco de dados, como diagramas ER (Entidade-Relacionamento).
- `MDB_RAFA.sql`: Script SQL para criação e/ou inserção de dados no banco de dados acadêmico.
- `escola (1).sql`: Script SQL relacionado à criação da estrutura do banco de dados da escola, incluindo tabelas, relacionamentos e possíveis dados iniciais.(Banco mais recente)
- `escola_mdbd.sql`: Script SQL que pode conter a definição completa ou parte do banco de dados acadêmico, incluindo tabelas, chaves e relacionamentos.
